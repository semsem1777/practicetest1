From Lead Type to Style Sheets

How the page moved from hand-set metal to code.

Old-fashioned typesetting

Old-fashioned typesetting is the traditional method of arranging individual letters, symbols, and spaces to create printed text. Originally, printers arranged metal type by hand before using a press to print pages. This method required considerable time, skill, and physical materials. Making changes or correcting mistakes could be difficult because the type often had to be rearranged manually.

Desktop publishing

Desktop publishing (DTP) uses computer software, such as Adobe InDesign, to design and arrange text and images for printed documents. Unlike traditional typesetting, DTP allows users to edit text, adjust layouts, change fonts, and move images quickly. It is faster and more flexible, making it useful for creating books, magazines, posters, and brochures.

HTML and CSS

HTML and CSS are technologies used to create and style web pages. HTML provides the structure and content of a page, such as headings, paragraphs, and images, while CSS controls its appearance, including colors, fonts, spacing, and layout. Unlike traditional typesetting and most desktop publishing, HTML and CSS are primarily designed for digital content that can adapt to different screen sizes and devices.

Overall, all three methods organize text and visual elements to communicate information clearly. However, traditional typesetting relies on physical materials, desktop publishing uses software to prepare documents for print or digital distribution, and HTML and CSS work together to structure and style content for the web.
