Google Docs v HTML

Writing in Google Docs and writing in an HTML document are different mainly in how the content is created, formatted, and displayed. Google Docs is a word-processing application
designed to make writing easy and accessible. Users can type directly into the document and use a toolbar to change fonts, adjust spacing, add headings, insert images, and organize
paragraphs without needing to know any code.

In contrast, HTML (HyperText Markup Language) is used to structure content on web pages. Instead of relying mainly on visual tools, writers use tags to tell a web browser how to
display text and other elements. For example, a heading can be written using the "h1" tag, while a paragraph is placed inside "p" tags. This means that writing in HTML requires some
understanding of coding and syntax.

Another key difference is how the content is displayed and shared. Google Docs automatically handles much of the formatting and allows users to collaborate with others in real time.
HTML documents, on the other hand, are typically viewed through a web browser and offer more control over how content appears on a website. Overall, Google Docs is generally better
for everyday writing and collaboration, while HTML is more useful for creating and organizing content for the web.
